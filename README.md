# Усовершенствование моделей асинхронного взаимодействия агентов на основании журналов событий мультиагентных систем 

## Структура проекта

```
courseProject3/
├── main.py                       # пайплайн синтеза (8 шагов)
├── compute_metrics.py            # обёртка fitness/precision (file-based)
├── requirements.txt
├── data/                         # IP-1..IP-12 — XES логи и эталоны
├── src/                          # ядро алгоритма
│   ├── synthesis_algorithm.py    # локализация каналов (ацикл./цикл.)
│   ├── async_agents.py           # композиция сетей Петри с каналами
│   ├── transitive_reduction.py   # удаление транзитивных каналов
│   ├── random_channel_removal.py # эвристическое удаление каналов под порог precision
│   ├── disconnected_agents.py    # композиция без каналов (нижняя граница precision)
│   ├── log_parser.py             # парсер XES → агенты
│   └── compute_metrics.py        # обёртка fitness/precision (object-based)
├── utils/
│   ├── enrich_logs.py            # обогащение логов (назначение transitions агентам)
│   ├── generate_hybrid_logs.py   # генерация гибридных логов (R~A)
│   └── hybrid_metrics.py         # гибридные метрики (Prec R1~A2 / A1~R2)
├── experiments/                  # экспериментальные/одноразовые скрипты
└── output/                       # сгенерированные финальные PNML-модели
```

---

## Установка

1. Требуется Python 3.9+.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # Linux/macOS
   source .venv/bin/activate
   ```
3. Установите зависимости (pm4py, pandas, numpy и т.д.):
   ```bash
   pip install -r requirements.txt
   ```

---

## Запуск пайплайна

###  Основной синтез

Запускает 8-шаговый пайплайн: проекция лога на агентов, майнинг локальных моделей, извлечение каналов-кандидатов, удаление транзитивно избыточных, гибридные метрики, эвристическое прореживание, итоговая композитная модель и метрики.

```bash
python main.py
```

Скрипт спросит номер датасета (например, `1` для IP-1). Финальная PNML-модель сохраняется в `output/`.

### Дополнительно: эксперименты

В папке `experiments/` лежат вспомогательные скрипты (batch-прогон по всем датасетам, проверка частных гипотез). Они не задокументированы и использовались для одноразовых прогонов.
